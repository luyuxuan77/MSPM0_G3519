二、按外设/模块分类
----------------------------------------

【1. 系统时钟 — SYSCTL】
  PA5   → HFXIN  (40 MHz 外部高速晶振输入)
  PA6   → HFXOUT (40 MHz 外部高速晶振输出)
  说明: 经 SYSPLL 倍频，CPUCLK = 80 MHz

【2. 调试接口 — DEBUGSS】
  PA19  → SWDIO  (SWD 数据线)
  PA20  → SWCLK  (SWD 时钟线)

【3. UART0 — 串口通信】
  PA10  → TX     (发送)
  PA11  → RX     (接收)
  参数: 波特率 115200, 8N1, 无流控

【4. UART1 — 蓝牙】
  PA8   → TX     (发送, Device Pin 22, PINCM19)
  PA9   → RX     (接收, Device Pin 23, PINCM20)
  参数: 波特率 115200, 8N1, 无流控

【5. UART4 — 步进驱动】
  PB10  → TX     (发送, Device Pin 34, PINCM27)
  PB18  → RX     (接收, Device Pin 59, PINCM44)
  参数: 波特率 115200, 8N1, 无流控

【6. SPI0 — OLED 显示屏 (SPI_0)】
  PB2   → PICO/MOSI  (主机输出，从机输入)
  PB3   → SCLK       (SPI 时钟)
  PC8   → DC         (数据/命令选择，GPIO软件控制)
  PC9   → CS         (片选，GPIO软件控制)
  PB23  → RES        (复位，GPIO控制)
  参数: 20 Mbps, MOTO3 模式 (CPOL=1, CPHA=1), MSB First, 8-bit

【7. SPI1 — IMU 惯性传感器 ICM45686 (SPI_1)】
  PB14  → POCI/MISO  (主机输入，从机输出)
  PB15  → PICO/MOSI  (主机输出，从机输入)
  PB16  → SCLK       (SPI 时钟)
  PB12  → CS_IMU     (片选，GPIO软件控制)
  参数: 200 kbps, MOTO3 模式 (CPOL=1, CPHA=1), MSB First, 8-bit

【8. TIMG0 PWM — 蜂鸣器】
  PB11  → CCP1  (PWM输出, Device Pin 35, PINCM28)
  说明: TIMG0 独立定时器，不与其他外设冲突

【9. TIMG6 PWM — WS2812 RGB 灯】
  PA29  → CCP0  (PWM通道0，占空比 50%)
  PA30  → CCP1  (PWM通道1，占空比 5%)
  参数: 总线时钟 80 MHz, 周期 100, 边沿对齐模式

【10. TIMA1 — 软件定时器】
  无外部引脚
  参数: 100 µs 周期, 总线时钟 /8 /100 = 100 kHz

【11. 4×4 矩阵键盘 — GPIO 扫描】
  行线 (输入，内部上拉):
    PC0  → R1  (Device Pin 46, PINCM74)
    PC1  → R2  (Device Pin 47, PINCM75)
    PC2  → R3  (Device Pin 50, PINCM76)
    PC3  → R4  (Device Pin 51, PINCM77)
  列线 (输出，推挽):
    PC4  → C1  (Device Pin 52, PINCM78)
    PC5  → C2  (Device Pin 53, PINCM79)
    PB21 → C3  (Device Pin 68, PINCM49)
    PC7  → C4  (Device Pin 64, PINCM85)
  说明: PC0~PC5, PC7 在 GPIOC 端口，PB21 在 GPIOB 端口；
        所有引脚均无 COMP 模拟功能，TIMx 复用仅作备选（默认 GPIO）

【12. ADC0 — 模拟输入】
  CH0 → PA27  (Device Pin 79, PINCM60)
  CH1 → PA26  (Device Pin 78, PINCM59)
  CH2 → PA25  (Device Pin 74, PINCM55)
  CH3 → PA24  (Device Pin 73, PINCM54)
  CH4 → PB25  (Device Pin 75, PINCM56)
  CH5 → PB24  (Device Pin 71, PINCM52)
  CH6 → PA16  (Device Pin 48, PINCM38)
  说明: 7 路 ADC0 输入，用于灰度传感器或其他模拟信号采集

【13. ADC1 — 模拟输入】
  CH0 → PA15  (Device Pin 44, PINCM37)
  说明: 1 路 ADC1 输入；PA15 与 DAC_OUT 共享引脚，使用 ADC 时不可同时使用 DAC

【14. 电机 PWM 与编码器】
  TIMG14 (MOTOR_PWM): 40 MHz, 四路 PWM
    CC0 → PB28  Motor0 PWM  (Device Pin 24, PINCM65)
    CC1 → PB13  Motor1 PWM  (Device Pin 37, PINCM30)
  TIMG9 (QEI_M0): Motor0 编码器
    PHA → PB29  (Device Pin 25, PINCM66)
    PHB → PB30  (Device Pin 26, PINCM67)
  TIMG8 (QEI_M1): Motor1 编码器
    PHA → PC6   (Device Pin 63, PINCM84)
    PHB → PA22  (Device Pin 62, PINCM47)
  方向控制 (GPIO):
    PA31 → Motor0 PH  (Device Pin  7, PINCM 6)
    PB0  → Motor1 PH  (Device Pin 15, PINCM12)
  说明: 与 TIMG6 RGB 灯使用不同定时器，无冲突

【15. GPIO — 独立控制引脚】
  PA14  → LED1 (L1), 输出, 初始高电平, 内部上拉
  PA17  → LED2 (L2), 输出, 初始低电平, 内部上拉
  PB31  → 用户按键, 输入, 下降沿中断, 内部上拉
